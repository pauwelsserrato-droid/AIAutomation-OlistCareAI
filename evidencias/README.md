# Evidencias

Las tres imagenes de esta carpeta son evidencias de diseno generadas desde la arquitectura y el JSON entregado.

Las capturas reales verificadas estan en `ejecucion-real/`. La lista exacta y su alcance se documentan en `docs/03_PRUEBAS_Y_EVIDENCIAS.md`.

No reemplazar capturas reales por montajes. La entrega debe diferenciar el diseno verificable de una ejecucion efectivamente realizada.
